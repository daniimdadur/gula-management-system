2. Latar Belakang
UMKM yang bergerak dalam produksi dan penjualan gula kelapa serta gula aren sering mengalami permasalahan dalam pengelolaan stok, pencatatan produksi, dan monitoring penjualan.
Proses yang masih dilakukan secara manual dapat menyebabkan:
* Kesalahan perhitungan stok.
* Sulit mengetahui jumlah barang yang tersedia.
* Sulit memantau pesanan pelanggan.
* Tidak adanya notifikasi ketika stok hampir habis.
* Sulit membuat laporan penjualan dan produksi.
Untuk mengatasi permasalahan tersebut, akan dibangun sebuah sistem berbasis web yang dapat mengelola seluruh proses bisnis mulai dari produksi hingga penjualan.
________________


3. Tujuan Produk
Tujuan utama sistem adalah:
1. Mempermudah pengelolaan stok barang.
2. Mempermudah pencatatan hasil produksi.
3. Mempermudah pengelolaan pesanan pelanggan.
4. Menyediakan dashboard monitoring bisnis.
5. Mengimplementasikan arsitektur Event-Driven menggunakan Kafka.
6. Menjadi studi kasus nyata pembelajaran Microservices.
________________

10. Non Functional Requirements
Performance
* Response API < 500 ms
* Dashboard < 2 detik
________________


Availability
* Service harus dapat berjalan secara independen.
* Kegagalan satu service tidak boleh menghentikan service lain.
________________


Scalability
* Service dapat di-scale secara terpisah.
* Kafka mampu menangani event secara asynchronous.
________________


Security
* JWT Authentication
* Role Based Access Control (RBAC)
* Password Hashing dengan BCrypt
________________
